# ThinkTutor 设计系统

本文件为全站视觉与交互依据。2026-09-04 根据用户选择更新为浅色专业工作台；2026-09-07 按要求改为顶部横向导航；2026-09-09 完成阅读字号与页面布局修订。
设计改版不改变产品角色、安全边界或知识包发布条件。

## 视觉方向

白色内容画布、浅灰导航底色、精密排版与明确的信息层级。
青绿用于主操作，蓝色用于信息状态，琥珀色用于待巩固内容，红色用于异常。
不使用虚构趋势图、数据、成绩或教师确认记录。

## 核心原则

1. 页面是工作空间，不是堆叠的卡片。使用分隔线、共享基线与留白组织内容。
2. 学习记录和独立表达是主体；分数辅助定位，证据支持评价。
3. 功能名称准确一致，避免口语化宣传、夸大承诺与无意义术语。
4. 保留所有角色权限、交互状态、错误反馈和可追溯信息。

## 排版与尺寸

- 系统 CJK 无衬线字体，不依赖远程字体。
- 页面标题 32px，移动端 28px；区块标题 20px，条目标题 16-18px。
- 界面文字与表单标签 16px；次级说明 15px；状态、计数和元数据最低 14px。
- 长篇研习记录与独立作答文字 18px、1.85-1.9 行高，正文最大约 72ch。
- 普通输入文字在桌面与移动端均为 16px，学习表达输入为 18px。
- 公共入口标题 52px，移动端 38px；不按视口宽度缩放字号。
- 字距为 0；数值使用等宽数字，不对正文使用等宽字体。
- 控件圆角 6px，记录容器 7px，独立内容卡片不超过 8px。
- 主要操作与表单控件高 48px；独立图标按钮至少 44px。

## 页面结构

- 不设置全站左侧导航。桌面品牌栏 84px，横向角色导航 60px；移动端品牌栏 76px。
- 960px 及以下从顶部展开导航，菜单占据正常文档流，保留全部角色入口。
- 普通内容上限 1320px，学习页与报告上限 1160px，任务表单上限 1080px，均居中。
- 学习总览：真实统计、研习记录、学习安排。无记录时显示明确空状态。
- 学习页：顶部任务上下文、横向阶段进度、下方研习记录与独立作答区。
- 创建任务：课程关联、研习目标、补充资料分组；桌面短字段并排、长文本通栏，移动端单列。提交操作单独成行。
- 教学表单：课程与任务的短字段双列、说明文本通栏；移动端单列，不改变字段含义与提交逻辑。
- 报告：评估摘要、五维能力评估、学习证据与定向巩固。
- 知识审核：版本概览、来源确认、样例校准、审核记录。
- 公共入口复用真实学习场景位图，不使用左右卡片式英雄区。

## 交互与无障碍

- 使用 Lucide 图标；图标按钮必须具有可访问名称和提示。
- 保留加载、成功、失败、重试、禁用和空状态。
- 顶部菜单使用自然键盘顺序，不遮挡内容；Escape 关闭并恢复焦点，切换到宽屏时重置展开状态。
- 横向阶段栏可聚焦滚动；阶段推进或尺寸变化时只横向定位当前阶段，不移动页面。
- 标签页支持方向键及 Home/End，未选中的内容不暴露到键盘焦点顺序。
- 当前页面和学习阶段使用 aria-current，状态不只靠颜色表达。
- 表格在窄屏内滚动；不裁切内容来掩盖溢出。
- 尊重减少动态效果的系统设置；不使用装饰性连续动画。

## 用语规范

- 学习总览 / 教学总览 / 管理总览：角色首页。
- 自主研习 / 课程任务 / 学习档案：学习入口与记录。
- 认知诊断 / 知识建构 / 迁移验证 / 费曼阐释 / 反思修订：教学阶段。
- 五维能力评估 / 待巩固要点 / 定向巩固：形成性反馈。
- 按钮直接表达动作，保留“登录”“提交回答”等明确命令。
- 原始学习证据、模型回答和评分结论不得为视觉包装而改写。

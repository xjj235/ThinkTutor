# 隐私数据流

用户资料与学习内容进入 Next.js 服务端，经 RDS 持久化；必要学习上下文发送给 DeepSeek；课程原文件直传私有 OSS，抽取文本由 Worker 写入 RDS；Redis 只保存短期限流、锁和任务状态，不是主数据。

日志禁止保存密码、Cookie、Key、完整 Prompt 和完整学生原文。AIUsage 保存匿名关联、官方 Token 与错误元数据。账号删除会删除个人认证与自主学习数据；教师拥有的课程若存在组织依赖，需要上线前确定软删除/移交政策，不能由代码静默决定。

隐私政策、未成年人处理、数据保留、第三方处理者、地域与可能的跨境义务必须由项目负责人和法律顾问上线前审核；本文不宣称法律合规已经完成。

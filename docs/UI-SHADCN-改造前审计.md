# shadcn 基准改造前审计

日期：2026-09-09。安全基线 `2ee1a2a`，分支 `codex/ui-shadcn-system`。

## 唯一基准

[shadcn-ui/ui](https://github.com/shadcn-ui/ui)，源码锁定 `3ba91b1cc83e1bbe4ab35a422ff2a694849c5048`。采用 new-york-v4 组件的语义 token 和操作界面规则，不混入其他产品风格。不复制示例业务数据或侧栏：本项目保留顶部导航、中文学习文本、已有图片和真实学习数据。

## 当前证据

- Next.js Web 应用，入口 `src/app/layout.tsx`，样式按 globals.css → tokens.css → workspace.css 加载。
- 本轮实跑 `pnpm preview:check preview-e2e/ui-readability.spec.ts preview-e2e/ui-design-audit.spec.ts`：14 通过。
- 页面范围：公共页 6、学生页 11、教师页 14、管理员页 6；每组覆盖桌面与手机。
- 本地证据：`.local-preview/ui-shadcn-2026-09-09/before/`，含各页截图、audit.json、字体信息、错误与加载态。
- 现有应用仅有浅色。系统深色偏好仍呈现浅色，不能当作深色已验收。
- 危险操作使用浏览器原生确认框；本轮已验证取消不发 PATCH。截图只能记录取消后的页面，不冒称浏览器确认框已经截图。
- 已有基础对比度、无溢出和键盘测试通过；这不等于视觉已经达到所选基准。

## 十项问题

| 项 | 具体证据与处置 |
| --- | --- |
| 对齐 | 导航/总览宽 1320px，任务宽 1080px，学习宽 1160px；顶层标题参考线不一致。统一页面栅格，阅读区作为内层约束。 |
| 间距 | 两份 CSS 对相同控件反复定义 padding、min-height；记录行 106px、工具条 38px、审核 tab 54px。重写单一组件规则。 |
| 字号 | 14/15/16/18/20/22/28/32/36/48/52px 混用。收敛为 14/16/18/20/32 五档。 |
| 颜色 | 灰蓝底、蓝色阶段标签、青绿色按钮及组件中的硬编码色并存。转为 shadcn 中性底、单一品牌强调色及独立危险色。 |
| 阴影 | 目前阴影总体克制，保留；统一为两个具名层级，删除旧 hero 图框影子规则。 |
| 圆角 | globals 与 workspace 对同一控件多次覆盖，仍有 2/4/6/8px、百分比和 999px。按控件/容器/头像明确定义，移除相互覆盖。 |
| 原生控件 | select 箭头和 checkbox 仍为平台默认，其他控件状态分散。保留原生语义，统一外观及 focus。 |
| 层级 | 任务表单横向过宽，标题、说明、输入纵向排列松散；学习页上下文占首屏过多。用分组栅格及紧凑顶部上下文重构。 |
| 状态 | EmptyState 已存在；学习与报告加载/无数据失败仍是一行文字，缺完整内容骨架和恢复入口布局。补共用状态组件。 |
| 装饰 | 现有图片没有遮挡学习操作，保留；不增加角色、背景光晕或营销装饰。 |

存在 7 类明确待处理问题，超过半数，因此替换 globals.css / workspace.css 样式层，而非继续追加覆盖。

# 学生知识点选择入口

学生可在“自主研习 → 创建研习任务”（`/learn/new`）选择五类金融风险主题，以及每主题八个知识单元，共 40 个单元。选择主题后可以直接开展综合学习，也可以选择一个具体单元；页面自动填写知识点和学习目标，学生选择学习者水平后即可开始既有学习闭环。

## 使用方式

1. 在“知识库研习”选择汇率风险、经济周期风险、利率风险、通货膨胀风险或政策风险。
2. 在“知识库单元”选择具体知识点，或保留“主题综合学习”。
3. 确认自动填写的目标，选择学习者水平，点击“创建并开始学习”。
4. 如需自由修改主题和目标，点击“改为自定义”。

选取知识库主题会解除班级课程/章节/目标绑定；选择班级课程会解除知识库选择，避免服务器采用另一套任务目标。已有课程授权逻辑继续生效。

## 资料使用边界

公开选题目录仅包含主题、单元 ID、标题和学习目标，所有环境均可选择并开始普通自主研习。草稿正文未启用时，页面显示“按所选主题开展自主研习；配套资料待审核”，会话使用现有模型知识回退路径。

开发或测试环境启用 `ALLOW_DRAFT_KNOWLEDGE=true` 后，才会检索已导入的学科知识正文，并优先检索学生所选单元。源文档 Prompt、教师答案和执行规则不会传入学生页面。没有自动发布草稿，也没有改变生产环境的资料发布门禁。

## 服务器行为

- `knowledgeSelection` 使用独立 Zod schema；服务器根据目录重新确定主题、目标和课程文字，不能由请求中的伪造文字覆盖。
- 拒绝未知主题、未知单元、跨主题单元，以及同时绑定课程/章节/学习目标/作业的请求。
- 选择结果以现有会话主题、目标和章节字段持久化，继续使用原有幂等机制，无数据库迁移。
- 定向巩固保留原知识点，更新薄弱项学习目标；连续重练、模型生成的其他主题目标或错误标签都不会将任务切换到系统性风险版本。
- 启用草稿预览时，重练首轮诊断也接入对应参考正文。

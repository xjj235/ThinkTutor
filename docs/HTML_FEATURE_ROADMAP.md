# ThinkTutor HTML 功能完善路线图

本路线图以最初的 MVP 实现说明和后续生产升级计划为功能基线。验收单位不是“存在一个 API”，而是一个完整纵向切片：HTML 页面、Route Handler、服务端授权、领域服务、PostgreSQL 数据、错误/空状态、桌面与移动布局、自动测试，以及本地与阿里云生产共用实现。

## 交付定义

一项面向学生、教师或管理员的功能只有同时满足以下条件才标记完成：

- 用户可以通过浏览器 HTML 页面找到并完成操作；
- 页面不直接访问数据库、AI 或长期云凭据；
- 输入经过 Zod，权限和资源归属由服务端判断；
- 失败有可重试或明确不可重试反馈，不静默丢数据；
- 本地 Mock 和阿里云生产使用同一页面、API、数据模型和状态机；
- 至少具备相称的单元、集成或 Playwright 证据；
- 1440px 和 375×812 不横向溢出，表单有标签并可键盘操作。

## 后续迭代顺序

### P0 — 上线安全与隐私闭环

1. 在真实阿里云环境验证 HTTPS、Secure Cookie、同源校验和安全 Header；
2. 完成真实 RDS/Tair/private OSS/RAM Role 联调；
3. 完成数据保留、账号删除、未成年人和第三方处理者法律文本审核；
4. 完成 RDS 恢复、告警、回滚和权限审计演练；
5. 使用显式开关执行一次真实 DeepSeek V4 Flash smoke。

### P1 — 网页功能深度

1. 为材料上传失败、重新处理和删除增加完整浏览器测试；
2. 教师页面补充更明确的任务筛选、分页和学生进度状态；
3. 管理员列表补充分页、搜索、危险操作二次确认和操作结果反馈；
4. 学习历史与档案增加可访问的筛选和空状态；
5. 在所有异步 HTML 操作中统一加载、成功、可重试错误组件。

### P2 — 真实运行质量

1. 真实数据规模下验证关键页面查询数量和分页上限；
2. 对 AI 延迟、429、网络故障、Tair/OSS 短暂故障执行生产级故障注入；
3. 校准 DeepSeek 报告质量与证据可追溯性；
4. 建立上线后的隐私事件、材料失败和 AI 错误运维流程。

## 明确不扩展

支付、会员、排行榜、社交、公开评论、直播、小程序、原生 App、家长端、心理或医学诊断不在当前产品计划内。只有用户明确批准后才能进入路线图。

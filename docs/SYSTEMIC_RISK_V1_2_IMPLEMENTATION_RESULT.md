## 发布前仍需真实完成

1. 由授权教师在HTML页面确认13个KU的真实来源、定位与文件校验值。
2. 录入至少20条覆盖L1-L4的教师确认样例，包含独立前序回答、迁移案例、证据/错误标签与五维分档；运行实际部署模型的校准，修正不一致后重新校准。
3. 校准通过后由版本负责人或管理员审核并发布，留下真实审核人和时间。当前无签署记录，不得手改状态绕过门槛。
4. 在授权的阿里云环境执行迁移、发布与HTTPS/数据库/存储/模型运行验收。本轮只完成本地检验，没有进行生产部署或云端验收。

发布门槛刻意保持关闭。当前语义判定和评分是可解释的工程规则，最终教学效度仍必须由教师样例与真实模型校准检验。测试日志存在pg并发查询弃用提示，但本轮未造成测试失败；升级pg前需单独验证适配器兼容性。

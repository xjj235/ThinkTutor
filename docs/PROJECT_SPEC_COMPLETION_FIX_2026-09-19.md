## 1. 达到轮数上限后仍完成独立费曼讲解

系统性风险 v1.2 达到练习上限后，现在先进入 `FEYNMAN_OUTPUT`，保存学生独立讲解，再进入 `REFLECTION`，最后生成报告。新进入该流程的会话将独立讲解与反思分别保存，反思不能替代独立表达。

练习上限、未掌握状态和迁移能力评分限制仍然保留；达到上限不会自动被视为掌握。已经处于反思阶段的旧会话继续兼容，避免中途改变历史会话进度。AI 失败不会推进阶段；相同请求重放返回当前已保存状态，不重复推进。

实现涉及 `src/lib/state-machine.ts`、`src/lib/knowledge/v12-session-service.ts`，并增加状态机、API/业务服务和桌面/移动浏览器回归。

## 2. 再练结束后复核原薄弱点，并支持继续巩固

通用学习和 v1.2 学习在生成再练报告时，均根据原薄弱点、本次学生表达和新报告进行针对性复核。复核结果和原文证据随新报告保存；原薄弱点在同一数据库事务中更新为 `RESOLVED` 或重新开放为 `OPEN`。

“已解决”需要模型判断与服务端证据条件同时成立：置信度至少 0.75、至少两条来自不同学生消息的实质且不同的原文证据，其中一条明确属于独立费曼讲解；涉及结构化知识的要点还必须通过对应知识状态/迁移核验。缺少证据、信心不足或仍待核验时保持可继续巩固，不能只因一次再练完成就宣称掌握。

伪造引用、错误消息归属和无效输出会使本次提交失败，保持原有阶段与薄弱点状态。报告、学生最终提交和原薄弱点更新具有事务一致性；并发提交、同一请求重放、跨用户引用和模型超时均有回归覆盖。Mock 模式明确返回证据不足，不产生虚假的掌握认定。

学生可在再练报告查看复核结果、依据和原要点入口；原报告显示最近再练报告或进行中会话的入口。原要点仍未解决时可以再次开始巩固。

新增 `LearningReport.retryReview` JSON 字段及显式 TypeScript/Zod 合同。迁移文件为 `prisma/migrations-postgresql/20260919060000_retry_gap_review/migration.sql`。该迁移还会重新开放旧版本中“子会话已完成并有报告、原要点却仍在巩固中”的记录；保留仍有活跃再练的记录和已经解决的记录，不追认旧学习结果为掌握。

实现主要涉及 `src/lib/retry-review.ts`、`src/lib/retry-lifecycle.ts`、两个会话服务、AI provider、报告序列化与 HTML 报告页。

## 3. 教师内容从创建到学生开始学习保持完整

课程、章节、目标、作业、前端表单与会话合同共用 `src/lib/content-limits.ts`。支持课程/章节各 120 字符、目标/任务标题 160 字符、目标正文 2000 字符、作业要求 4000 字符、学习者水平 100 字符；学习会话正文允许 4000 字符，以完整接收合法目标和作业要求。

教师创建后、学生选择时和最终数据库保存均不静默截断。相关页面增加长文本换行；章节与目标表单修正异步提交后重置表单的事件引用问题。

回归覆盖合法上限、超限拒绝、教师实际 HTML 创建目标和作业、学生选择目标开始学习、从班级作业开始学习，以及两种入口保存全文的一致性。

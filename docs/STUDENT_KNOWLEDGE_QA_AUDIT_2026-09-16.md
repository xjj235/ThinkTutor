# 学生知识问答检查与修复（2026-09-16）

本轮范围为学生选择知识主题/单元后，创建任务、诊断、苏格拉底追问、提示、费曼讲解、报告、定向重练及失败恢复。保留工作区已有修改；导入的原始文档作为参考数据，不作为开发或运行指令。没有更改知识发布审核门禁。

## 三个修改方案与选择

| 方案 | 做法 | 评估 |
| --- | --- | --- |
| 一 | 只调整提示词与界面说明 | 无法解决错误计数、并发与断线重复提交，未选用。 |
| 二 | 修复服务端判定、模型输出约束与浏览器恢复；补充可复现回归 | 直接修复已发现问题，保留现有学习循环，采用。 |
| 三 | 重写问答引擎与状态模型 | 影响已有知识流程、发布规则及学习记录，范围与回归成本过大，未选用。 |

## 已定位的问题与实现

| 问题/复现 | 修复 |
| --- | --- |
| “汇率上涨不会必然让企业亏损，因为……”被 `includes('不会')` 当成不知道；短知识答案也被误判 | 只将完整的未知/求助表达视为低信息，保留带实质内容的回答。 |
| 连续申请提示始终给模型 level 1 | 按已保存提示递增到 1/2/3；未知回答自动得到的支架也纳入计数；失败/重放不增加次数，提示不提高轮数或掌握度。 |
| 第三轮刚提出证据题，未回答就能进入费曼 | 服务端和页面动作共用已回答题型判定；只有学生实质作答才计入，当前提交恰好计入一次。 |
| 同一事务中回答与下一问可能同毫秒，数据库按时间排序不稳定 | 新消息时间严格递增；读取按 `createdAt,id` 排序。增加未来时钟偏差与旧同时间消息回归。 |
| 已保存回答/讲解但响应断开后，编辑清除请求 ID，旧题答案会作为下一题再次提交 | 保留原正文和请求 ID，未确认结果时锁住其他操作，原操作幂等恢复；终止性错误可同步服务器进度，未保存原文留在可复制区域，不自动填入下一题。 |
| 创建成功后导航尚未结束，按钮重新开放 | 同步请求锁覆盖同帧双提交，成功导航期间保持锁定。 |
| 目标确认/恢复核验失败后重试错误动作或共享旧 ID | 每种事件保存各自请求 ID，纳入正确的重试动作和等待文案。 |
| 不同请求 ID 并发重练同一 OPEN 漏洞，可能产生两个子会话 | 事务内条件更新 OPEN→IN_PROGRESS，并检查抢占结果；失败回滚，不生成第二个子会话。 |
| 所有漏洞已启动巩固，原报告仍显示可创建，错误后无限重试 | 报告返回状态，只有 OPEN 可创建；进行中显示“巩固已开始”，不可重试错误提供重新加载。 |
| 用户可编辑任务字段直接插入 system 提示 | 课程、章节、主题、目标、水平和材料留在不可信用户消息中，系统模板仅保留字段说明与服务端阶段数据。 |
| 真实模型返回未定义题型、多问号或原样重复上一问 | 所有操作发送完整 JSON Schema；诊断固定概念澄清/提问动作；显式约束单问题；提示动作与重复问题在服务端复核，不合格自动重生成。 |
| 报告推理耗尽 4000 token，返回空正文；或评价引用不对应学生原文 | 报告生成预算增加到 8000，重试递增；超过 25 分的维度及优势必须有逐字学生引用，不能引用教练来支持学生能力。缺乏证据只允许最低档并说明不足；区分漏洞解释中引用题干/缺少的术语与明确的学生引文。 |

报告引文校验只能验证归属与是否逐字匹配，不能证明模型对学科内容及能力的解释一定正确。提示与报告进一步要求澄清主体/方向、避免把一个概念的证据外推成另一个概念。

## 本轮验证记录

- 单元/集成：`pnpm test`，549 passed / 8 skipped（45 个文件通过，2 个默认不启用的真实模型文件跳过）。真实模型另行显式执行，不用历史测试代替本轮结果。
- 40 个知识单元矩阵：全部经过持久化创建、未知回答、提示、有效追问、费曼、报告、重练；每次模型输入检查选定知识单元优先、无系统性风险串题；检查 OPEN→IN_PROGRESS。最终 40/40 通过。
- 浏览器：桌面 1440×900 与手机 375×812；常规组合 44 个实例，首次最终组合中 40 通过、4 个恢复文本框标签断言失败；修正明确可访问名称后做定向复测。另有目标确认/恢复核验 2 个实例及课程目标 2 个实例通过。最终汇总见文末。
- 真实模型：用户明确授权后执行 `deepseek-v4-flash`。首两轮各 3/5 通过，暴露题型、空报告、提示重复及报告引文归属校验过严的问题；修复后第三轮 5/5（14 次调用），最终提示约束更新后第四轮再次 5/5（15 次调用，1 次报告证据失败由自动重试恢复）。
- 真实样本覆盖五主题各一个单元的诊断与追问，以及汇率单元的三级提示和报告；使用合成学生回答，无真实学生个人数据。它不是 40 个单元的完整真实模型教学校准，也不等于生产环境或教师验收。

原始真实样本与失败记录位于 `.data/knowledge-qa-live/round1-failed.json`、`round2-failed.json`、`round3-passed.json`、`round4-passed.json`；只记录输出正文、结束原因及 token 数，不记录密钥或内部推理。浏览器截图/故障记录分别在 `.data/qa-e2e-core/`、`.data/qa-e2e-events/`、`.data/qa-e2e-recovery-final/`。

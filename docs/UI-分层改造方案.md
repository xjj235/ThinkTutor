## 验收目标

1. 37页面双视口检查不退步；导航在顶部、正文至少16、对话18、主动作48、图标44。
2. 标准正文/次级文案抽样对比度>=4.5:1；控件边界目标>=3:1。截图图像背景不纳入简单固色探针。
3. 主内容移动边距16，列表表头与数据文本对齐，统计项内边距一致。
4. 字体仍为本地中文sans栈，不新增外网请求；截图与错误数来自本轮。
5. loading/error/disabled/focus/hover/active/reduced-motion均有测量或交互证据；空态采用真实空查询，原生confirm验证取消不提交。
6. 不宣称没有的暗色/自定义弹窗，不以Mock闭环代替真实模型效果验收。

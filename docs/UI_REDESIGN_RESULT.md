## 已实施范围

- 学生、教师、管理员统一侧栏导航与顶部上下文栏；登录后首页直接进入对应工作区。
- 学习总览使用真实统计、研习记录与学习安排；空数据不生成虚构分数或趋势。
- 创建任务先呈现课程关联和必填目标，再呈现补充信息。
- 学习页区分任务上下文、阶段进度、研习记录和独立作答区；新消息滚动到最新位置。
- 报告采用摘要、五维能力评估、证据和定向巩固的分层布局。
- 知识审核分为版本概览、来源确认、样例校准和审核记录；证据选项显示中文定义及原始编号。
- 登录、注册、学习方法、学习档案和学习分析统一排版与术语；补齐浏览器品牌图标。
- 移动导航支持焦点约束、Escape 关闭与焦点恢复；后台内容在抽屉打开时不可交互。
- 审核标签支持方向键、Home/End；隐藏表单保留输入状态。
- 移动端输入字号 16px，保留所有角色入口和学习阶段。

设计依据已同步到 DESIGN.md 与 design-system/thinktutor/MASTER.md。

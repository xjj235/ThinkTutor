# 学习输入字数限制取消与验证

日期：2026-09-09。本报告仅记录本轮代码与验证结果。

## 改动范围

- 普通作答：取消 10 字最低要求及 2000 字上限。
- 费曼阐释、反思修订：取消 30 字最低要求及 4000 字上限。
- 前端删除 `maxLength` 与字数配额提示；按钮仅在空白或提交中禁用。
- 共享输入 Schema 仅校验非空，保留首尾空白清理，不截断回答正文。
- 移除普通服务和 v1.2 服务中的 `MAX_USER_MESSAGE_LENGTH` 校验；旧环境变量不再生效。
- 追问接收完整本轮回答，不再受内部 20000 字输入校验限制；允许逐字引用单字回答。
- Mock 评估长回答时仅缩短证据引文，正文完整传入、保存，不改真实模型评分或知识库标准。
- JSON 请求采用与现有 Nginx 一致的 2 MiB 整包字节保护，按流实际字节校验；超大请求返回 413，不推进学习状态。这不是教学字数配额，模型上下文容量也仍是实际技术边界。
- 保留消息总量、调用频率、并发锁、阶段校验、证据审核和幂等保护。课程名称、任务字段和密码等不属于本次作答调整范围。

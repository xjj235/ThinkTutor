保留系统 CJK 无衬线字体，无远程字体请求；本机 Chrome 实测使用 Microsoft YaHei。正文采用 1.7 行高，学习长文采用 1.85-1.9 行高、约 72ch 最大行宽。字距为零，不随视口宽度连续缩放字号。

## 页面改造

- 总览与档案：统计区采用连续浅灰底色；主题、目标、状态和进入操作对齐。窄屏将状态安排在主题下方，避免挤压主标题。
- 自主任务：明确区分课程关联、研习目标和补充资料；知识点与水平在桌面并列，学习目标通栏；提交操作独立成行。
- 学习页：上下文和阶段仍在页面顶部；阶段名称、辅助标签、问题正文分层；学习记录高度增加，正文和作答同步放大。
- 报告页：标题、总分、总结、五维评价与原文证据分别组织；修复标题过弱、评价区间距过大和进度条贴近文字的问题。移动端评分摘要纵向排列。
- 教学表单：短字段双列，课程标题和长说明通栏；移动端单列。未改变字段值、校验或提交接口。
- 管理、知识审核和资料页：共享更新筛选器、表格、标签页、状态、输入和辅助文字尺寸；表格只在自身容器内横向滚动。
- 公共页：保留原有学习图片，调整文字尺寸和移动端换行，下一节在首屏留有入口。
